# 源码发行说明

本发行版只包含 RTL Lab 平台源码、网页、测试、调用脚本、无密钥配置示例，以及原项目的反应计时器/计算器教学示例。完整安装和使用步骤见 [README](../README.md)。

## 包含与排除

- 包含 `app.py`、兼容 `config.py`、启动脚本、`workbench/`、`anlogic/`、`tools/`、两个示例工程和 `tests/` 中列明类型的源文件。
- 包含 README、原始 LICENSE、本页、模型配置示例、本机工具配置示例和发布脚本。
- 不包含 `.tools/`、安装包、可执行文件、动态库、许可证、密钥、运行时数据库、个人实验或聊天历史。
- 不包含 `workbench.local.json`、内部任务记录、开发计划及含本机部署信息的历史验证文档。
- 测试用 TD 日志是解析器固定样例，用户名及个人路径已匿名化；它们不是当前用户的实验结果。

`.gitignore` 负责 Git 的排除规则，`scripts/build_release.py` 则使用独立的文件清单生成压缩包。直接压缩开发目录不会自动应用这些规则。

## 生成发布包

```powershell
python scripts/build_release.py --version 0.1.0 --output dist
```

输出：

```text
dist/
  rtl-lab-v0.1.0/                  可作为 GitHub 仓库根目录的干净源码
  rtl-lab-v0.1.0-source.zip         含同一份源码的 ZIP
  rtl-lab-v0.1.0-source.zip.sha256  ZIP 的 SHA-256 校验值
```

源码目录中还有 `RELEASE_MANIFEST.json`，列出每个源文件的 SHA-256。校验文件本身不列入其自身清单。打包器拒绝覆盖已有同名输出；修改源文件后应使用新的输出目录或新的版本号重新构建。

打包前会检查包含范围、符号链接/目录联接、常见密钥特征和异常大的源文件。异常源文件检查仅用于避免把运行产物混入发行包，与仿真日志和波形的运行上限无关。公开前仍需检查实际文件清单以及新添加资料的内容。

校验 ZIP：

```powershell
Get-FileHash .\rtl-lab-v0.1.0-source.zip -Algorithm SHA256
```

应与同目录 `.sha256` 文件中的值一致。

## 上传 GitHub

把生成的 `rtl-lab-v0.1.0/` 当作仓库根目录。确认其中没有自己的本机配置和运行目录，再初始化 Git、提交并推送到自己指定的仓库。保留 `.gitignore` 与 `LICENSE`。

源码包没有嵌入 TD、ModelSim 或 OpenCode；工具安装与授权由使用者自行配置。原平台 BSD 许可证不替代第三方工具各自的许可条件。后续更新发布时，应记录新增功能、已验证工具版本以及兼容性变化。

## 本版验证范围

发布前验证干净 ZIP 的文件清单与哈希、无配置启动网页、独立目录中的路径解析、模型设置界面，以及配置现有本机工具后的小设计功能仿真、TD 实现和 SDF 后仿真。

网页在含中文及空格的目录可以启动；ModelSim SE 2020.4 在中文工作目录的编译数据库创建失败。请按 README 使用较短的英文项目路径运行实际 EDA 流程。

模型参数/工具交互测试使用本地测试服务；没有把 API Key 放入包中，也不在打包期间调用付费模型或进行 FPGA 烧录。Windows + TD 4.6.7 / ModelSim 2020.4 是当前验证组合。ORFS 的远程安装与不同站点库配置不随源码包交付，其他机器需按自己的环境验证。
