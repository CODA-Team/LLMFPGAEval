    MODEL CONNECTION

    API 与模型设置

    直接填写模型配置 JSON。官方 API 或任意兼容中转站使用同一格式，可保存多个模型并选择使用哪一个。

    JSON 是实际保存的模型配置；编辑完成后点击“保存设置”即可。

    配置格式与字段说明
    {
  "我的模型": {
    "provider_id": "my-provider",
    "model_id": "model-id",
    "base_url": "https://api.example.com/v1",
    "api_key_env": "MY_API_KEY",
    "npm": "@ai-sdk/openai-compatible",
    "usage_adapter": "openai-chat-v1",
    "user_agent": "Mozilla/5.0",
    "settings": {}
  }
}

    npm 选择协议：@ai-sdk/openai-compatible（Chat Completions）、@ai-sdk/openai（Responses）、@ai-sdk/deepseek 或 @ai-sdk/anthropic。settings 填模型参数，例如 reasoningEffort、max_tokens、temperature、top_p；空对象表示不额外指定参数。

    api_key_env 是环境变量名称，不是密钥本身。usage_adapter 为用量格式标识，可用 openai-chat-v1、deepseek-v1、openai-responses-v1、anthropic-v1；token 数据由 OpenCode 统一记录。可选 headers 填附加非鉴权请求头，limit 可声明模型的 context 与 output 容量。

    网页输入的密钥绑定当前 api_key_env；无需写入 JSON。不同环境变量的密钥分别保存。

    运行与并行上限（默认不限制）

    不同实验独立运行和停止；同一实验按顺序执行。API 与工具路径设置由所有实验共用，运行结束后可修改。

    以上各项独立设置，留空不限制，填写正整数后从下一轮开始生效。失败后重跑也计次数，自动续跑不会重置额度；你仍可随时点击停止。一步指一次助手模型迭代，可包含多个工具调用。

    单次输出 token 不等于整个实验累计用量。模型异常截断会在同一会话自动续跑，次数上限也可选填。
